# 🚲 Bike Rental Shop

A PostgreSQL-based Bike Rental Shop project built using Bash Shell Scripting and SQL.  
This project was created as part of the FreeCodeCamp Relational Database Certification.

The project demonstrates relational database management, SQL query operations, and Bash scripting automation for managing bike rentals and customer records.

---

## 🚀 Features

- Rent available bikes
- Return rented bikes
- Manage customer information
- Track bike availability
- Store rental history
- Execute SQL queries using Bash scripting

---

## 🛠️ Technologies Used

- PostgreSQL
- SQL
- Bash Shell Scripting
